## ◼ About

I take binaries apart to understand how they really work — then build clean, fast, native software on top of that knowledge.
Most of my time goes into **reverse engineering**, **low-level C++** and the tooling around **Flawless**.

- ◻ Reading compiled code like source: x64 assembly, calling conventions, vtables, RTTI
- ◻ Mapping undocumented structures and keeping them alive across updates
- ◻ Writing hooks, pattern scanners and overlays that stay fast and stable
- ◻ Shipping the full stack around a product — from the native core to the web panel

<br/>

## ◼ Reverse Engineering

| Area | What I do |
| :-- | :-- |
| **Static analysis** | Disassembly & decompilation, control-flow recovery, function and type reconstruction |
| **Dynamic analysis** | Debugging, breakpoints & tracing, runtime memory inspection |
| **Memory** | Structure reversing, pointer chains, offset tables, version-resilient layouts |
| **Signatures** | Byte-pattern & RTTI scanning to survive binary updates without hardcoded addresses |
| **Hooking** | Inline / detour hooks, instruction-length decoding, hand-written x64 shellcode |
| **Rendering** | DirectX 11 overlays, world-to-screen math, skeleton & mesh data |
